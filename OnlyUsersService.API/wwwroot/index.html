Service Architecture

OnlyUsersService is a decoupled .NET 8 microservice replicating the CMS.UserManagement structure with Entity Framework Core, SQL Server ORM, JWT Bearer authentication, and Swagger OpenAPI testing.

  • Solution: OnlyUsersService.sln
  • Web API Project: OnlyUsersService.API
  • Database: OnlyUsersService_DB (SQL Server / LocalDB)
  • ORM: Entity Framework Core 8 with Migrations
  • Authentication: HMAC-SHA256 JWT with Claims & Role Authorization
  • Password Hashing: BCrypt encryption
  • Service URL: http://localhost:5200/swagger
